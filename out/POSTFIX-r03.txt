Post-comparison fix to the revision 0.3 implementation, 2026-10-18.

After the r03 freeze (out/FROZEN-r03.txt) and comparison (compare/comparison-r03.json), a review of the frozen code found a runner crash that no vector reaches. With a nonempty approvers list and a conditional entry whose action is [] or {}, out_of_scope called approvers_well_formed before the contract door, and building the set of conditional actions raised TypeError. run_all exited 1 with no output. The contract door alone already refuses such a contract.

Fix: approvers_well_formed now checks each conditional entry (an object whose action is a nonempty string) before building the set, and returns false otherwise, so the contract reaches the door and is refused (contract_not_verified). Two regression tests run the case through run_all.run_one, with a list and with an object as the action.
